## 11. Search Console Setup Required (Post-Deployment)

1. Open [Google Search Console](https://search.google.com/search-console)
2. Add domain property: `brytwin.consulting`
3. Complete DNS TXT verification
4. Submit sitemap: `https://www.brytwin.consulting/sitemap.xml`
5. Use URL Inspection on `https://www.brytwin.consulting/`
6. Run "Test Live URL"
7. Request indexing
8. Repeat for: `/properties`, `/services`, `/about`, `/gallery`, `/contact`
